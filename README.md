# 智泊 · 小区停车管理系统

Vue3 + Element Plus 前端 / Express + MySQL 后端的小区停车管理系统，内置 25 套主题可随时切换（默认玻璃拟态）。

实现方式：`src/styles/themes.css` 用约 40 个语义 token（`--surface` / `--border` / `--shadow` / `--blur` / `--primary` / `--login-card` …）定义每套配色，组件只消费 token。Element Plus 的 `--el-*` 统一映射到 token，并用 `color-mix()` 派生浅色档位，因此新增深色主题不需要单独写一套 Element 样式。

新增主题只需在 `themes.css` 追加一段 `[data-theme="xxx"] { ... }`，再在 `composables/useTheme.js` 的 `THEMES` 里加一条预览信息。

## 鉴权与自动续期

采用 access token + refresh token 双令牌方案：

| 令牌 | 有效期 | 存放 | 说明 |
|---|---|---|---|
| access token | 30 分钟 | localStorage `token` | 每次请求放在 `Authorization: Bearer` |
| refresh token | 7 天（滑动续期） | localStorage `refreshToken` | 同时落库 `refresh_tokens` 表，可服务端撤销 |

运行机制：

- **主动续期**：请求前检测 access token 剩余 < 5 分钟，先静默刷新再发请求，避免请求白跑一趟。
- **401 兜底**：接口返回 401 时用 refresh token 静默换新令牌并**重放原请求**，用户无感知。
- **并发合并**：页面同时发出多个请求时，只发起一次刷新，其余排队等待结果。
- **令牌旋转**：每次刷新都签发新的 refresh token 并作废旧令牌，防止令牌被重放。
- **彻底失效**：refresh token 也无效时，清空本地凭证 + 同步清空 pinia 状态，跳回登录页并带 `?redirect=`，登录后自动回到原页面。
- **强制下线**：修改 / 重置密码后，服务端撤销该账号全部刷新令牌。

## 功能模块

| 模块 | 说明 |
|---|---|
| 登录认证 | 双令牌鉴权，admin/operator 两种角色，token 失效自动跳登录页 |
| 布局交互 | 左侧菜单可收缩为图标栏（220px ⇄ 72px），折叠状态本地记忆，收缩时悬停显示菜单名称；切换页面带淡入上浮过渡并自动滚回顶部 |
| 数据看板 | 车位统计、今日/本月收入、近7日收费趋势图（ECharts）、车位使用率仪表盘、月卡到期提醒 |
| 车位管理 | 车位图 / 车位列表双 Tab 切换，分区管理，车位类型（固定/临时）、状态（空闲/占用/停用）、绑定住户车辆，分页 |
| 车辆管理 | 住户/临时车辆档案、月卡及有效期，按车牌/车主/电话/房号搜索，分页 |
| 进出管理 | 入场自动分配车位（固定车位优先），出场自动计费（免费时长 + 小时计费向上取整 + 每日封顶），月卡有效免费，预缴费，记录分页与条件查询 |
| 月卡缴费 | 续费计价、未到期顺延、缴费记录分页 |
| 收费规则 | 免费时长/小时单价/每日封顶/月卡价格 可配置 |
| 系统用户 | 管理员可增删账号，操作员无权限访问（403） |
| 操作日志 | 关键操作留痕，分页 |

## 数据库

`parking_system` 库：users / zones / spots / vehicles / fee_rules / records / payments / logs，见 `db/schema.sql`；演示数据见 `db/seed.sql`。

## 计费规则

- 免费时长内（默认15分钟）不收费，0 元出场记为"免费"
- 超出后按小时向上取整 × 单价，单日封顶
- 月卡在有效期内出场免费，月卡续费在到期日基础上顺延
