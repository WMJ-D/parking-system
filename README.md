# 智泊 · 小区停车管理系统

Vue3 + Element Plus 前端 / Express + MySQL 后端的小区停车管理系统，内置 25 套主题可随时切换（默认玻璃拟态）。

实现方式：`src/styles/themes.css` 用约 40 个语义 token（`--surface` / `--border` / `--shadow` / `--blur` / `--primary` / `--login-card` …）定义每套配色，组件只消费 token。Element Plus 的 `--el-*` 统一映射到 token，并用 `color-mix()` 派生浅色档位，因此新增深色主题不需要单独写一套 Element 样式。

新增主题只需在 `themes.css` 追加一段 `[data-theme="xxx"] { ... }`，再在 `composables/useTheme.js` 的 `THEMES` 里加一条预览信息。

## 启动


## 鉴权与自动续期

采用 access token + refresh token 双令牌方案：

| 令牌 | 有效期 | 存放 | 说明 |
|---|---|---|---|
| access token | 30 分钟 | localStorage `token` | 每次请求放在 `Authorization: Bearer` |
| refresh token | 7 天（滑动续期） | localStorage `refreshToken` | 同时落库 `refresh_tokens` 表，可服务端撤销 |

运行机制：

- **主动续期**：请求前检测 access token 剩余 < 5 分钟，先静默刷新再发请求，避免请求白跑一趟。
- **401 兜底**：接口返回 401 时用 refresh token 静默换新令牌并**重放原请求**，用户无感知。
- **并发合并**：页面同时发出多个请求时，只发起一次刷新，其余排队等待结果。
- **令牌旋转**：每次刷新都签发新的 refresh token 并作废旧令牌，防止令牌被重放。
- **彻底失效**：refresh token 也无效时，清空本地凭证 + 同步清空 pinia 状态，跳回登录页并带 `?redirect=`，登录后自动回到原页面。
- **强制下线**：修改 / 重置密码后，服务端撤销该账号全部刷新令牌。

## AI 助手

顶栏右侧「AI 助手」按钮展开右侧 AI 对话分栏：左侧系统主内容自动收缩为左右并排布局（展开/收起带过渡动画，窄窗口自动占满），支持用自然语言完成数据查询、业务办理和页面跳转（Agent 能力），回答以 SSE 流式逐字输出。

### 大模型配置

管理员点击面板右上角齿轮，填写 OpenAI 兼容接口（API 地址、API Key、模型名称），「测试连接」通过后保存：

| 服务商 | API 地址 | 模型示例 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Moonshot | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |

地址填到 `/v1` 即可，系统自动补全 `/chat/completions`。API Key 仅以掩码返回；仅管理员可修改配置，操作员可正常对话。

### 能力清单

| 能力 | 说明 |
|---|---|

| 业务办理 | 登记车辆、车辆入场（自动分配车位）、车辆出场（自动计费）、月卡续费、结清欠费、新增车位/分区、修改收费规则 |
| 页面导航 | 说「打开欠费管理」即自动跳转对应页面 |
| 报表导出 | 收入报表、进出记录、操作日志一键导出 Excel；AI 可直接对话触发浏览器下载 |
| 多轮对话 | 会话按用户隔离存库，可查看历史、新建/删除会话 |
| 流式输出 | SSE 逐字返回，首字即显示；工具执行徽章实时出现；支持中途停止生成 |

示例问句：

- 今天经营情况怎么样？
- 现在有多少空闲车位？
- 列出 30 天内到期的月卡
- 帮我登记车辆：京A12345，车主王小明，电话13800138000
- 把京A12345 开进场 / 办理出场
- 打开欠费管理页面

实现方式：`POST /api/ai/chat/stream` 以 SSE 返回事件流（`meta` 会话信息 → `delta` 文本增量 → `tool` 工具执行 → `navigate` 跳转 → `download` 文件下载 → `done` 完成），前端用 fetch 流式读取并逐字渲染，支持中途停止；`POST /api/ai/chat` 为非流式兼容接口。Agent 以 OpenAI function calling 驱动工具调用（单次最多 6 轮），工具直接复用业务 SQL 与计费规则；所有写操作都会记录操作日志（`AI 登记车辆` / `AI 车辆出场` 等）。删除类高风险操作未开放给 AI，写操作失败会如实返回原因。导出文件统一由 `exceljs` 生成 `.xlsx`（收入报表 / 进出记录 / 操作日志）。

## 数据库

`parking_system` 库：users / zones / spots / vehicles / fee_rules / records / payments / logs / ai_config / ai_conversations / ai_messages，见 `db/schema.sql`；演示数据见 `db/seed.sql`，AI 相关表也可用 `db/ai.sql` 单独升级。

## 计费规则

- 免费时长内（默认15分钟）不收费，0 元出场记为"免费"
- 超出后按小时向上取整 × 单价，单日封顶
- 月卡在有效期内出场免费，月卡续费在到期日基础上顺延
